Routes

User Authentication:
        /signup POST - Create a new user account.
        /login POST - Log in to an existing account. [aadhar card number + passsword]
Voting:
    /candidates: GET - Get the list of candidates.
    /vote/:candidateId: POST - Vote for a specific candidate

Vote counts: 
    /vote/counts: GET - Get the list of candidate sorted by there vote count

User Profile: 
    /profile: GET - Get the user's profile information
    /profile/password: PUT - chnage the user's password

Admin candidate Management: 
    /candidates: POST - Create a new candidate.
    /candidates/:candidateId: PUT - Update an existing candidate.
    /candidates/:candidateId: DELETE - Delete  a candidate from this list
